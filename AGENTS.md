# Project

The project is named BetterHoster.

# Design colors

Always use this palette for the Minecraft server dashboard.

## Backgrounds & surfaces
- Page background: `#111111`
- Sidebar: `#161616`
- Cards: `#1B1B1B`
- Inputs: `#202020`
- Secondary button: `#242424`
- Selected row: `#292929`
- Hover: `#383838`
- Borders / dividers: `#303030`

## Text & icons
- Primary text: `#EDEDED`
- Secondary text: `#888888`
- Disabled text: `#666666`
- Primary buttons: `#EDEDED`
- Button text (on white): `#111111`
- Icons: `#BEBEBE`

## Action colors
- Start: `#79A887`
- Restart: `#D1A76A`
- Stop: `#C77979`
- Delete: `#AA5555`
- Save: `#EDEDED`
- Edit: `#303030`
- Console: `#303030`
- Disabled: `#242424`

## Statuses & feedback
- Running / success: `#79A887`
- Starting / warning: `#D1A76A`
- Stopped / error: `#C77979`
- Installing / processing: `#A99ABC`
- Offline / inactive: `#858585`
- Selected / focus: `#D5D5D5`

## Typography
- Use the system sans-serif font stack: `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`.

## Scope and authentication
- Do not add setup tokens, extra authentication steps, or other unrequested access requirements. Follow the user's specified scope; ask before adding requirements that materially change the requested flow.
- Do not add unrequested warnings, notices, or extra restrictions to the interface.
- Show errors in custom, styled popups by default unless the user requests another presentation. Do not use built-in browser alerts, confirms, or prompts.
- Do not add unrequested titles, branding, or sidebar text.

- Use custom, themed dropdowns instead of native browser dropdown menus.

## Git branches
- Commit only to the `BETA` branch unless the user explicitly instructs otherwise.
